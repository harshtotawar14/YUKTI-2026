O. BOOKING STATE MACHINE
===============================================================

Enforce valid server-side transitions.

Normal flow:

REQUESTED

→ VALIDATING

→ MATCHING

→ OFFERING

→ ASSIGNED

→ TRAVELING

→ ARRIVED

→ IDENTITY_VERIFIED

→ CUSTOMER_CONFIRMED

→ SERVICE_STARTED

→ IN_PROGRESS

→ COMPLETION_REQUESTED

→ COMPLETED

→ PAYMENT_PENDING

→ PAID

→ CLOSED

Alternate flows:

WORKER_CANCELLED

→ FINDING_REPLACEMENT

CANCELLED

FAILED_MATCH

DISPUTED

Never allow arbitrary status jumps.

Example:

REQUESTED
must not directly become
SERVICE_STARTED.

===============================================================
W. CONCURRENCY CONTROL
===============================================================

Critical requirement:

Only ONE worker may become confirmed for a normal one-worker booking.

Prevent race conditions using:

database transaction

atomic update

locking where appropriate

unique constraints

Do not rely on frontend state.

===============================================================
X. SMART WORKER REPLACEMENT ENGINE
===============================================================

If assigned worker cancels:

do NOT immediately kill the customer booking.

Flow:

WORKER_CANCELLED

→ release worker schedule

→ FINDING_REPLACEMENT

→ re-check candidates

→ eligibility

→ ranking

→ offer replacement

→ replacement accepts

→ assignment updated

→ customer notification

Store:

cancellation reason

replacement time

replacement worker

attempts

===============================================================
Y. DUAL SERVICE-START VERIFICATION
===============================================================

Flagship workflow.

Server flow:

booking accepted

→ worker traveling

→ worker arrives

→ location/booking check

→ identity/liveness verification

→ identity match success

→ generate booking-specific dynamic QR/token

→ customer scans

→ customer confirms

→ service allowed to start

Critical rule:

IDENTITY VERIFIED

AND

CUSTOMER CONFIRMED

must both be true.

Otherwise:

SERVICE MUST NOT START.
